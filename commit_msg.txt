feat(app): scaffold FastAPI app skeleton (Phase 3 Slice α1)

Bootstraps the Phase 3 application architecture without business
logic. Slice α2 will add the first auth use case on top.

New modules:
- app/core: config (pydantic-settings), logging (structlog), error
  tree + handlers (API_CONTRACT §1.2 codes), request-id middleware,
  DI container.
- app/application/interfaces: IUnitOfWork, IUserRepository ports.
- app/infrastructure: async SQLAlchemy session factory, UoW impl,
  Argon2id PasswordHasher, JWT service (ADR-0008 primitives), and
  a per-request UserRepository.
- app/api/v1: dependency providers + health/readiness router.
- app/main: FastAPI factory (--factory mode, no module-level app).

New deps:
- runtime: fastapi >=0.115, argon2-cffi >=23.1, pyjwt[crypto] >=2.9,
  uvicorn[standard] >=0.32
- dev: httpx >=0.27

Tests: 32 new unit tests (pytest -m unit total: 56, coverage 88.65%)
and 7 new integration tests against the live DB (4 repository, 3
health). All HTTP tests use httpx.AsyncClient + ASGITransport rather
than starlette.testclient.TestClient (Starlette 1.x deprecation).

Notable design choices and Windows workarounds:
- No module-level `app`; uvicorn must use `--factory`. Lets the
  test fixture inject Settings without setting env at import time.
- import-linter contract 3 now allows indirect infrastructure imports
  so the composition-root pattern works; direct infra imports inside
  app.api remain forbidden.
- HTTP_422_UNPROCESSABLE_ENTITY -> HTTP_422_UNPROCESSABLE_CONTENT
  (Starlette 1.x / RFC 9110 rename).
- WindowsSelectorEventLoopPolicy set at module import in main.py and
  tests/integration/conftest.py for psycopg async compatibility.
- Added scripts/run_dev.py: a Windows-friendly dev server entry
  point that constructs uvicorn with an explicit Selector loop
  factory (uvicorn's CLI uses asyncio.run(loop_factory=...) which
  bypasses the global event-loop policy on Python 3.12+).

Validation: CI gate 10/10 green; pytest -m integration 7/7 pass;
scripts/run_dev.py boot + /healthz 200 OK confirmed locally.
